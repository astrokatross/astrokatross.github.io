The second data release for the GaLactic and Extragalactic All-sky Murchison Widefield Array eXtended (GLEAM-X) Survey. This data release covers the South Galactic Pole (SGP) region, roughly 12,000 sq.deg, and has an associated catalogue of over 600,000 components.
